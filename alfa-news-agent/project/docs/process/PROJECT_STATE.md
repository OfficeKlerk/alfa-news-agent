# Состояние проекта — перед сдачей

> Одностраничник для команды: что готово, что осталось и **что именно** нужно, чтобы это закрыть (деньги / владелец шлюза / жюри / эксперт). Дата: 2026-10-25. Актуально к master после серии TASKS6–9.

## Продукт в одной фразе
Персональная новостная аналитика для крупного бизнеса: профиль компании → отбор значимых событий → интерпретация с источниками и позицией банка → уточняющие вопросы. Не лента-пересказ, а объяснение влияния на конкретную компанию, с трассировкой и защитой от галлюцинаций.

## Готово (влито в master)
- **Ядро:** бизнес-профиль из CSV (`company_context`), признаки и ранжирование новостей (`news_analysis`), агент + LLM + RAG + UI (`server`, `frontend`), общие контракты `contracts/v1` и `/v1` gateway.
- **Персонализация:** одна новость — разный приоритет под компанию (измеримо, демо-матрица).
- **Качество (реальные прогоны):** ранжирование nDCG@3 ≈ 0.93–0.97; RAG hit@3 ≈ 0.93 (28 запросов); baseline BM25 + цель-метрика для вектора.
- **Надёжность / анти-галлюцинации:** дословные цитаты для факта/банка; отклонение выдуманных чисел и финэффектов; `monitoring_only` при сохранении ставки (в т.ч. «регулятор» без явного ЦБ); строгий JSON по типизированной схеме (факт/банк/AI, пути к реальным полям); bounded repair с точной диагностикой; лимит генерации против зацикливания.
- **Данные/RAG:** проверенные даты банковских документов, подключены проверенные реальные новости; оценка ретрива + **оценка свежести/разнообразия** выдачи.
- **Настройки LLM:** подобраны (`reasoning_effort=none`, `max_tokens` достаточно) — полный JSON в срок, обрезка устранена.
- **Проверки:** Node + Python тесты зелёные; `dev.py --smoke`; контракты; **UI/gateway-проверка 15/15** (0 платных вызовов); портируемость тестов на Windows.
- **Материалы:** дек защиты `docs/defense/deck.html`, сценарий `docs/guides/DEMO_SCRIPT.md`, мониторинг-дашборд `docs/dashboard/`, карта проекта `docs/INDEX.md`.

## Честные оговорки (говорить жюри)
- Прохождение схемы и механических проверок **не равно** смысловой безошибочности — последнее требует независимого эксперта (пока авто-ревью).
- На диагностической выборке принято ~1/2–3/6 анализов; отклонения — это работающие защиты, а не «сломанная модель».
- Где у банка нет материала — не выдумываем, помечаем. Тариф LLM — механика учёта готова, число уточняется у организаторов.
