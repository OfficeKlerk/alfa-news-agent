# Restore verified bank publication dates and connect reviewed real news

Рабочий `/v1` RAG исключал все 64 OCR-страницы: в метаданных отсутствовали даты. Также в локальном наборе были только шесть demo-новостей.

## Изменения

- По самим оригинальным PDF визуально подтверждены восемь дней публикации; 56 страниц получили метаданные. OCR, ID, страницы и URL сохранены. Реестр содержит напечатанную дату, страницу доказательства и SHA-256 PDF.
- Для Gold_digest_August26 точный день не указан на восьми проверенных страницах. Неподтверждённое «1 августа» удалено; восемь страниц остаются честно недатированными и исключёнными из `as_of`-анализа.
- Добавлены три проверенные дословные выдержки ЦБ/СО ЕЭС/Минтранса с первичными URL, датами и хешами. Это не полные статьи/AI-пересказы. HTML/PDF не публикуются заново.
- При запуске новые публикации добавляются и в существующую SQLite без удаления demo. Повторный импорт идемпотентен и не затирает более поздние редакции. Docker-образ включает reviewed-набор.
- Добавлены офлайн-проверка реестра и интеграционные тесты дат, будущих источников, разрешения цитат, реальных новостей и полного HTTP-пути.

## Проверка

`npm run typecheck`, `npm test` (110/110), `npm run build` и `python scripts/verify_bank_metadata.py --pdf-dir <оригинальные PDF>` прошли. Тест анализа использует подставной транспорт LLM и профиль/ранжирование; вызовов внешней модели нет. Новые зависимости и API-контракты не добавлялись.

Проверяющему: [инструкция и доказательства](BANK_DATES_AND_REAL_NEWS.md). Для `/v1` использовать `python scripts/dev.py --native-providers --data-dir data`; стандартные mocks остаются mocks. Реальный live-прогон требует отдельной конфигурации и проверки качества. Требуется получить подтверждённый день публикации обзора золота от первоисточника, если нужно включить и его.
