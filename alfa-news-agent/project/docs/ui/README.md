# Референс-карточка инсайта (роль 4)

`insight_card.html` — самодостаточный прототип карточки события для UI Альфа-Бизнеса. Открывается в браузере без сборки и сети (данные зашиты внутри). Назначение — **образец для роли 4**, не замена рабочего `frontend/`.

## Что показывает (закрывает P0/P1 роли 4)

- **Разделение факт / позиция банка / вывод AI** — три визуально разных блока с подписями:
  - серый «Что произошло · факт»,
  - красный «Позиция Альфа-Банка» с цитатой ЦМИ и ссылкой на документ,
  - фиолетовый «Вывод AI» с пометкой уверенности и «сформировано моделью, не позиция банка».
- **Честный статус банка:** где у банка нет материала (`bank.available=false`) — пунктирный блок «нет материала», позиция банка не выдумывается (соответствует `data/demo/news_bank_mapping.json`).
- **Персонализация:** переключатель 3 компаний показывает, как одна новость (ставка) значима для экспортёра с кредитами и малозначима для энергетики без кредитов (пилюля релевантности меняется, риски/возможности скрываются).
- **Состояния** loading / empty / error (кнопки справа), ошибка — без тихой подмены live↔demo.
- **Трассировка:** блок «На чём основано · источники» со ссылками на первоисточник; у «почему важно» — указатель на признак профиля.

## Дизайн-решения (по ui-ux-pro-max)

- **Стиль:** Minimalism / Swiss — чистая сетка, воздух, высокий контраст, чёткая иерархия (подходит для enterprise-дашбордов и финтеха).
- **Шрифт:** IBM Plex Sans (банковский/финтех mood: trustworthy, corporate) через Google Fonts.
- **Цвета:** бренд Альфа (красный `#EF3124`) как главный акцент; три семантических блока — факт (нейтральный серый), банк (красный), вывод AI (**профессиональный синий**, не фиолетовый — по правилу «избегать AI-фиолетового» для финтех-доверия).
- **Доступность:** `:focus-visible` для клавиатуры, `prefers-reduced-motion` отключает анимацию скелетона, контраст текста ≥4.5:1, ховеры 200мс.
- **Адаптив:** проверено на 375px — риски/возможности схлопываются в одну колонку, без горизонтального скролла.

## Как интегрировать в рабочий `frontend/`

Карточка строится из объекта, который маппится на контракт `Analysis` (`contracts/v1`). Соответствие полей:

| Блок UI | Поле контракта/данных |
|---|---|
| Что произошло · факт | `Event.title` / `Event.text`, `fact_status` |
| Почему важно | вывод агента + `evidence` (JSON Pointer на признак профиля) |
| Риски / Возможности | `Analysis` → risks / opportunities |
| Позиция банка | RAG-результат по `news_bank_mapping`: `bank_view` + источник (doc, page); при отсутствии — флаг «нет материала» |
| Вывод AI | `Analysis` вывод модели + `confidence` |
| Источники | `Event.sources` / `trace` |

Роль 4 заменяет объект `INSIGHTS` на реальный ответ `/v1` (AnalysisResponse), сохранив разметку и классы. Цвета/лейблы блоков менять не нужно — они и есть требуемое разделение.

> Данные синтетические (`is_mock`). Прототип не ходит в сеть и не тратит бюджет.
