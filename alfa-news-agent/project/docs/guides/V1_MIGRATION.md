# Миграция фронтенда на /v1 (роль 4)

Продуктовый UI (`frontend/`) исторически работает на legacy `/api`. Этот шаг добавляет **opt-in режим `/v1`** через адаптер — без слома рабочего `/api`.

## Как включить / выключить
- Включить: открыть UI с `?api=v1` (запоминается в `localStorage`).
- Выключить: `?api=legacy` (сбрасывает запоминание).
- По умолчанию — `/api` (ничего не меняется).

## Что переведено на /v1 (проверено вживую на интеграционном стенде)
Адаптер `frontend/v1-adapter.js` перехватывает те же `/api`-пути, что зовёт `app.js`, и отдаёт данные из `/v1` в форме, которую ждёт существующий рендер:

| Операция UI | /api (legacy) | /v1 |
|---|---|---|
| Старт/статистика | `GET /api/bootstrap` | синтез из `GET /v1/health` + `GET /v1/companies` |
| Список/поиск компаний | `GET /api/companies` | `GET /v1/companies` |
| Профиль компании | `GET /api/companies/:id` | `GET /v1/companies/:id` (Profile) |
| Лента событий | `GET /api/feed` | `POST /v1/tools/search_news` + `POST /v1/rank` |
| Анализ | `POST /api/analysis` + поллинг `GET /api/jobs/:id` | `POST /v1/analyze` (**синхронно**; job эмулируется адаптером) |
| Анализ по id | `GET /api/analyses/:id` | `GET /v1/analyses/:id` |
| Уточняющий вопрос | `POST /api/analyses/:id/questions` | `POST /v1/analyses/:id/questions` |
| Аналитика банка (библиотека) | `GET /api/research` | `POST /v1/tools/rag_bank_analytics` |

Разделение **факт / позиция банка / вывод AI**, честный блок «позиция банка не выделена», источники, риски, вопросы — рендерятся из `/v1` без изменений UI.

## Чего ещё нет в /v1 (блокирует полный дефолт-cutover — задача роли 3/5)
В `/v1`-режиме эти действия возвращают понятную ошибку, т.к. эндпоинтов нет:
- **Добавление новости** (`POST /api/news`) — нужен `/v1` ingest.
- **RSS-обновление** (`POST /api/feeds/refresh`) — нужен `/v1` эндпоинт.

Когда они появятся в `/v1`, адаптер дополняется, и `/v1` можно сделать режимом по умолчанию.

## Как проверить локально
```bash
npm ci && npm run build
python scripts/dev.py            # поднимает Python API + Node gateway + моки на :8000
# открыть http://127.0.0.1:8000/?api=v1   — UI на /v1
# открыть http://127.0.0.1:8000/?api=legacy — UI на /api (дефолт)
```

Проверено: bootstrap, профиль, лента (search+rank), синхронный анализ (claims fact/bank/ai), источники, уточняющий вопрос — работают в `/v1`-режиме; `/api`-режим не затронут; ошибок в консоли нет.
