# Исправленный проект: публикация ленты и диалога

Все изменения включены в исходники. Основа — master d49ddc219e55430418d2806dc5c55c0f15cacd7a.

Рабочая папка — эта папка с корневым package.json. Актуальные изменения находятся
в корневых server/, integration/ и contracts/. Вложенная project/ сохранена из
исходного репозитория как историческая копия.

Исправлено:
1. Лента публикует только успешно завершённые, проверенные и сохранённые результаты компании и роли.
2. Незавершённые, отклонённые и устаревшие результаты доступны в технических данных, без подстановки в основную ленту.
3. Ошибка одной новости не блокирует сохранение и публикацию другой.
4. Неудачный дополнительный вопрос не меняет предыдущий диалог.
5. Доступные карточки считаются отдельно от архива версий; признак выполнения учитывает только действующие аренды заданий.

Описание API и проверок: docs/integration/FEED_PUBLICATION.md.
Установка и запуск: README.md. Требуются Node.js 24 и зависимости Python-сервисов.

Проверки исходников:

```bash
npm ci
npm run typecheck
npm test
npm run build
```
