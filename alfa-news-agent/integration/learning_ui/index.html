Обучение ранжировщика

Оцените полезность новости для компании. Коэффициенты будут подбираться автоматически, когда накопится достаточно проверенных оценок. Ответы агента, клики и прогнозы модели не становятся разметкой.

Обучение включается через scripts/dev.py --learning --context-db …

Шкала: 0 — не относится к бизнесу; 1 — общий фон; 2 — полезна для решения; 3 — требует срочного внимания с подтверждённой связью с компанией. Если не уверены, оставьте «Пропустить».

Порядок карточек не зависит от прогноза модели. Это рабочая обратная связь; независимую контрольную разметку собирайте отдельно.
