От новости к обоснованному выводу
Анализ учитывает профиль выбранной компании. Факты, предположения и рекомендации показываются отдельно; недостающие данные остаются явно обозначенными.
Подготовка контекста доступна без ключа модели. Она показывает профиль, оценку релевантности и источники; генерация ответа подключается отдельно.
