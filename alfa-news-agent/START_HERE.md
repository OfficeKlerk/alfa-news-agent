## Что перенесено

- Публикация только проверенных, успешно сохранённых и актуальных карточек выбранной компании и роли.
- Отдельные точные счётчики доступных карточек и фактически выполняющихся заданий.
- Независимое выполнение новостей и сохранение предыдущего диалога при сбое вопроса.
- Согласованные сервер, JSON Schema, OpenAPI и тесты.
- Новый интерфейс: автоматическое обновление ленты, сохранение черновиков и безопасная повторная проверка отправки вопроса.

Правила содержательной проверки новостей и ответов модели в рамках очистки не ослаблялись.

## Что удалено

Вложенные копии `alfa-news-agent/` и `project/`, старые пакеты `delivery-task2/`,
`verification/`, `evidence/`, устаревшие обзоры кода `docs/archive/`, старые патчи
и манифесты. В ZIP нет Git-истории, `node_modules`, сборки `dist`, кешей или окружения Python.
Рабочие данные, обучающие наборы, тесты, инструкции запуска и файлы лицензий сохранены.

`config/source-manifest.json` содержит актуальные контрольные суммы исходников.
Исторические отчёты в `docs/reports/` оставлены для контекста и не являются результатами текущей проверки.

## Как распаковать

Распакуйте ZIP в **новый пустой каталог**. Он создаст ровно одну папку
`alfa-news-agent/`. Откройте её: внутри сразу должны быть `package.json` и `server/`.
Не распаковывайте архив внутрь существующей папки проекта: это снова создаст вложенную копию.
Копирование поверх старой папки также не удаляет старые файлы.

Установка и режимы запуска описаны в [README.md](README.md), защищённый live-запуск —
в [deploy/MERGED_RELEASE.md](deploy/MERGED_RELEASE.md). Нужны Node.js 24.13–24.x и Python 3.12.
Зависимости устанавливаются заново; собственные настройки и runtime-данные подключаются отдельно.

## Проверки и повторная упаковка

На этой сборке прошли 504 Node-теста, 257 Python-тестов, typecheck, build,
проверка контрактов, пять офлайн-сценариев анализа, аудит встроенного ранжирования
и три HTTP smoke-конфигурации (default, Python ranker + legacy agent, native providers).
Внешняя платная модель и production-стенд не вызывались.

```sh
python scripts/package_source.py --check
npm ci
npm run typecheck
npm test
npm run build
python -m pip install -r requirements-dev.txt -c requirements.lock
python scripts/build_contracts.py --check
python -m pytest tests -q
```

Повторная упаковка без зависимостей, сборки и вложенных копий:

```sh
python scripts/package_source.py --out ../alfa-news-agent-clean.zip
```

В Git-копии упаковщик использует отслеживаемые файлы текущего рабочего дерева;
новые исходники перед упаковкой добавьте в индекс (`git add`). В распакованном
ZIP он использует перечень из `config/source-manifest.json`. Манифест обновляется
при упаковке; `--check` только проверяет его. Команды не отправляют ничего на GitHub.
