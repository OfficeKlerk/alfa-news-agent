`project/` содержит полный проект коллеги плюс нашу последнюю версию и исправления стыковки. Ни один исходный файл коллеги не удалён; сравнение по SHA — evidence/source-comparison.json. GitHub не изменялся.

Начните с:
- project/docs/reports/MERGED_PIPELINE_REVIEW_20261025.md — оценка, сохранённые функции, исправления, проверки и ограничения.
- project/deploy/MERGED_RELEASE.md — актуальный запуск полного live-контура с OIDC.

454 Node-теста и 257 Python-тестов пройдены; сборка/контракты/native HTTP smoke прошли. Реальные IdP/Qwen, Docker/VPS и суточный прогон ещё требуют стенда. Платных вызовов в этой проверке нет.

ВАЖНО: до закрытия неопределённого исхода платного POST держите генерацию выключенной. Существующий резерв токенов не гарантирует отсутствие повторной оплаты после timeout/crash. Избранное/история live сейчас общие внутри компании, а не индивидуальные у каждого сотрудника. Подробности и исполнители — в указанных документах.

На VPS 2 ГБ начните с одного gateway и встроенного worker с concurrency=1; ML, retrieval/collector и agent также нужны. Qwen удалённая. Нельзя считать память/нагрузку подтверждёнными без измерения.

verification/ внутри проекта — сохранённые исторические материалы коллеги; DELIVERY_REVIEW — наш предыдущий отчёт. Актуальные доказательства объединения — evidence/ рядом с project, общий MANIFEST и SHA256SUMS.

changes.patch — совокупный патч к чистому master 0e6403e0dfb918448493701fb696750551c911bb. Полный project уже содержит патч; повторно поверх него не применять. Для чистого checkout: git apply --check /path/changes.patch, затем git apply /path/changes.patch. Patch проверен реальным применением и сравнением всех исходников. Команды не делают push.

Ключи, JWT, приватный env, runtime SQLite, база компаний, скачанные полные статьи, зависимости и .git не включены. Реальные входные данные подключаются отдельно. Исходные публичные данные/fixtures проекта сохранены.
