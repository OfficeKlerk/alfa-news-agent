## Воспроизведение

Из корня проекта после установки зависимостей по README:

```bash
python scripts/build_contracts.py --check
npm run build
npm test
python -m unittest discover -s tests -q
python -m pytest -q -rs
RANK_MODE=news-analysis NEWS_MODULE_PATH=. python scripts/dev.py --smoke --native-providers
```

Повторить локальный прогон с сохранённым приватным кешем и исходной базой организаторов:

```bash
python scripts/fetch_weekly_news.py
node --import tsx scripts/ingest_weekly_news.ts --input var/weekly-audit-20261024/articles.json --out var/weekly-audit-20261024/events.json --as-of 2026-10-24T12:41:46Z
python scripts/analyze_weekly_news.py --events var/weekly-audit-20261024/events.json --database /path/to/companies.sqlite --out data/weekly_audit_20261024/results.json --previous data/weekly_audit_20261024/results_before.json --report docs/reports/WEEKLY_NEWS_RESULTS_20261024.md
```

`fetch_weekly_news.py` по умолчанию читает уже полученный кеш; `--fetch` обновляет семь HTML-страниц через curl с проверкой TLS. Три страницы НТБ получены web-reader и требуют соответствующих JSON-снимков с полями `url`, `title`, `text`, `published_display`, `acquisition`. Повторное извлечение проверяет дату и hash текста: изменившаяся страница, включая изменяемый URL ЦБ, не подменит снимок молча. Без исходной базы и кеша доступны сохранённые результаты, но полный недельный прогон офлайн не воспроизводится. Оригинальные тексты и полная база в архив исходников не включены.

## Что пока не доказано и где остаются ограничения

- Недельная подборка использована для исправления правил; независимого человеческого ревью и проверки на новых отложенных данных нет. Второй AI проверил расчёты и ограничения, но это не экспертная разметка.
- Правила НТБ об интервенциях пока не получают отраслевой связи: текст не называет зерно, участие оптовика неизвестно. Это возможный пропуск, а не основание объявить новость бесполезной.
- Проекты бюджета/мощностей и обсуждение ГОСТов определяются по теме, но статус принятого решения остаётся неизвестным. Советы по ним общие. Третья позиция при наличии только двух совпадений не означает третью важную новость.
- Названия компаний обезличены; нельзя надёжно связать публичные новости о конкретных контрагентах с ID. Время наблюдения профилей неизвестно: это проверка доступного снимка, не исторический backtest. ФТС не задаёт направление торговли; платёж не подтверждает договорную роль.
- Нет условий кредитов, открытой позиции, фактических активов и оценённого эффекта действий. Финансовые сценарии в реальном прогоне не запрашивались; убытки, выгода и оптимальная стратегия не рассчитывались.
- Семантика настоящих ответов внешней LLM и позиция банка на реальных новостях этим прогоном не проверены. Лексические ограничения не гарантируют истинность каждого утверждения. Docker и UI в браузере в эту проверку не входили.
