# Задача №7: ОКВЭД и финансовые показатели

Ветка `codex/okved-validation`, база `541c778` (master с PR #20–23).

## Проблема

Фраза «Компания работает в отрасли (ОКВЭД 49.42), финансируемой из бюджета» распознавалась как финансовый показатель: десятичный код находился рядом со словом «финансируемой». Из-за этого сохранённый черновик анализа перевозчика U_100215 отклонялся с `AI financial figures must be verbatim fact/bank quotes, not company impact`.

## Изменение

Финансовая проверка отдельно учитывает явно подписанный ОКВЭД/OKVED, если точный код выбран этим claim из типизированного бизнес-листа `okved_code` или `okved_division` через `profile_paths`. Исключение передаётся только разделам, связанным с этим claim; для limitations/missing_data используются коды из выбранных оснований ответа.

Проверка происхождения чисел не изменена. Неподтверждённый код, код из произвольного текстового поля, сумма или процент с теми же цифрами не получают исключения. Явные денежные и процентные единицы проверяются до исключения кода. Неподписанные числа и даты сохраняют прежние правила. Не меняются промпт, repair, контракты и бизнес-выводы модели.

## Проверки

- До исправления две новые регрессии на подтверждённый код падали; после проходят.
- 6 новых тестов: наблюдавшийся код, составной код, типизированное происхождение, неподтверждённые значения, финансовое повторное использование цифр, разделы и уточняющий вопрос.
- Все 156 Node-тестов прошли, TypeScript и сборка прошли.
- Пять офлайн-сценариев LLM прошли механические проверки.
- HTTP smoke с Python-аналитикой и отдельными Node-провайдерами прошёл.
- Сохранённый второй черновик transport-carrier из расширенного прогона повторно проверен офлайн на исходном контексте: теперь grounding проходит. Реальные данные компании не включены в тестовый код или этот документ.

Внешняя LLM не вызывалась. Это исправление ложного технического отказа; оно не подтверждает смысловую правильность всего старого черновика и не закрывает остальные задачи команды. В частности, трактовка loan=false и применимость бюджетной программы остаются отдельной проверкой.
