# Проверка персонализации: исходная разметка

Первый результат — [таблица «компания × новость × оценка × причина»](../../data/personalization/annotation_table.md):
3 компании, 13 реальных исторических событий, 39 оценок. Это небольшой набор для
поиска ошибок персонализации и разработки признаков, без нового демо.

Оценки назначены AI по [явной рубрике](../../data/personalization/RUBRIC.md) до
просмотра скорингов и весов. 22 оценки равны 0, 12 — 1, 5 — 2; оценок 3 нет,
поскольку существенность, применимость и срочность для конкретных компаний
одновременно не подтверждены. Ни одна оценка не является экспертным gold или
наблюдением финансового результата.

## События и проверка источников

12 событий переиспользованы из существующей курации `training_v2`: снижение и
сохранение ставки, общий и гостиничный НДС, тариф взносов ИТ-организаций, зерновой
индекс ФАО, две меры ЕС, экспорт топлива, наличная валюта, переводы нерезидентов
и музейная выставка как отрицательный контроль совпадения по Москве.

Добавлено одно реальное отраслевое сообщение [СО ЕЭС от 12.08.2026](https://www.so-ups.ru/news/newonsite-view/news/30816/)
о новой редакции порядка соответствия генерирующего оборудования техническим
требованиям. Это даёт профильный пример для энергетической компании. Прочитано
сообщение о публикации редакции, а не сам нормативный документ; участие компании
в оптовом рынке и перечень её оборудования остаются неизвестными.

Все 13 источников повторно проверены 24.10.2026: 11 страниц прочитаны напрямую,
два сообщения — о топливе и выставке — доступны только в индексированных
выдержках первоисточников. [Реестр проверки](../../data/personalization/source_verification.json)
содержит URL, короткую буквальную цитату, способ доступа и ограничение для каждого
события. Фактические пересказы в `events.json` не обозначены как цитаты.

Источник ФНС о взносах содержит несколько тем; выбранное событие относится
именно к ИТ-организациям. Вся страница не должна автоматически получать ту же
метку, что выбранный фрагмент. Исходные даты имеют точность до дня: техническое
время `23:59:59Z` — консервативная граница дня, не измеренное время публикации.

## Воспроизводимость и слепая проверка

| Файл | Содержание |
|---|---|
| `data/personalization/events.json` | 13 событий с источниками; первые 12 сохранены из исходной курации. |
| `data/personalization/articles.json` | Только входы для извлечения: заголовок, фактический AI-пересказ, URL и даты; без тегов, признаков и оценок. Это не полный оригинальный корпус статей. |
| `data/personalization/profiles.jsonl` | 3 канонических профиля со ссылками на записи и хешами исходных CSV. |
| `data/personalization/graph_evidence.jsonl` | 39 экспортов `one_hop_payment_share_v1` по всем наблюдаемым платежам; совпадение по широкому ОКВЭД/региону не доказывает экономической связи. |
| `data/personalization/labels.jsonl` | Замороженные оценки, причины, точные JSON Pointer и значения полей, неизвестные параметры и происхождение. |
| `data/personalization/review_template.jsonl` | Шаблон второго разметчика без AI-меток и объяснений. |
| `data/personalization/manifest.json` | Происхождение, ограничения, хеши и время заморозки. |

Замороженный SHA-256 `labels.jsonl`:
`49848944e04dc509a410e7e4c7333533a0b119fb770cc204e7eb230bbac2a7ad`.
Метки не исправляются под результат ранжирования. Дополнительные оценки другого
разметчика следует сохранять отдельным файлом; расхождения разбирать явно.

Для второго участника: открыть рубрику, источники и профили, заполнить отдельную
копию `review_template.jsonl` до просмотра таблицы и метрик. `label_origin=human`
допустим только для реальной проверки человеком. Слепой второй AI-проход полезен
для обнаружения несогласованности, но не заменяет участника или эксперта. На
момент фиксации исходного набора проверенных человеком пар: **0**.

Проверка целостности без SQLite, сети и дополнительных библиотек:

```bash
python data/personalization/validate.py
```

При наличии исходной полной базы можно выгрузить профили и граф в новую пустую
папку, не перезаписывая зафиксированные данные:

```bash
python data/personalization/build_snapshots.py --database data/processed/company_context.sqlite --output-dir data/processed/personalization_rebuilt
```

Граф экспортирован реализацией v1 на базовой ревизии `023070d`; изменение правил
графа при будущей пересборке может изменить его значения. Хеши закрепляют локальные
снимки и пересказы, не неизменность удалённых сайтов. Валидатор проверяет структуру,
матрицу, ссылки на поля и происхождение; он не подтверждает истинность AI-оценок.

## Пределы этой проверки

Наличие большой группы проверено, но адресные новости о членах группы не покрыты:
для этого нет подтверждённого сопоставления публичных названий с обезличенными ID.
Искусственные сопоставления не добавлены. Проверка платёжного канала покрыта
примером дорожной компании и топливных контрагентов, с сохранением неизвестных
договорных ролей и экспортного статуса.

Выборка целевая: компании, события и некоторые нормы коррелируют. После изменения
признаков по её ошибкам сравнение «до/после» показывает исправление этих ошибок,
а не ожидаемое качество на новых компаниях. Нужен отдельный, заранее отложенный
набор новых событий с независимой человеческой проверкой. Среднее по трём
компаниям и 39 зависимым парам не заменяет такого испытания.
