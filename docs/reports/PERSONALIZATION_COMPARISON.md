# Персонализация: сравнение до и после

Сравнение 3 компаний × 13 исторических событий по 39 заранее замороженным AI-оценкам. Метки и коэффициенты при выполнении скрипта не изменяются; обучение не запускается.

**Возраст каждой новости равен нулю**: она оценивается на собственную дату публикации с доступным снимком компании. Это изоляция предметной релевантности при ретроспективном сценарии, не хронологическая лента и не backtest. Дата наблюдения полей компаний неизвестна.

Два отдельных сравнения: (1) исходные курированные типы/отрасли и добавленные только из текста event_details; (2) прежний RSS-вход other с пустыми измерениями против текущего извлечения. Во втором случае входы — фактические AI-пересказы реальных первоисточников, не полный оригинальный корпус статей.

## Метрики

NDCG использует линейную выгоду 0–3 из существующего `scripts/evaluate_ranking.py`. Значимая новость для precision/recall — оценка ≥2. Усреднение по компаниям равновесное. У компаний всего 2, 2 и 1 значимых события: даже идеальный precision@5 здесь ограничен числом таких событий.

| Вариант | k | NDCG | Precision | Recall | NDCG с усреднением ничьих |
|---|---:|---:|---:|---:|---:|
| Курированные события / v1 | 3 | 0.7335 | 0.4444 | 0.8333 | 0.7274 |
| Курированные события / v1 | 5 | 0.7222 | 0.3333 | 1.0000 | 0.6970 |
| Те же события + извлечение / v2 | 3 | 0.8680 | 0.5556 | 1.0000 | 0.8680 |
| Те же события + извлечение / v2 | 5 | 0.8317 | 0.3333 | 1.0000 | 0.7887 |
| Пересказы / прежний other | 3 | 0.5212 | 0.2222 | 0.3333 | 0.3371 |
| Пересказы / прежний other | 5 | 0.4961 | 0.1333 | 0.3333 | 0.3882 |
| Пересказы / извлечение + v2 | 3 | 0.9212 | 0.5556 | 1.0000 | 0.9081 |
| Пересказы / извлечение + v2 | 5 | 0.8381 | 0.3333 | 1.0000 | 0.8083 |

При одинаковом балле порядок определяется `news_id`, а не смыслом новости. Последняя колонка — точное ожидаемое значение при случайной перестановке внутри каждого блока равных баллов; это устраняет эффект удачного алфавитного порядка. Доверительные интервалы и статистическая значимость не заявляются.

## Ограничения и воспроизведение

Исходная таблица и обоснования: [PERSONALIZATION_LABELS.md](PERSONALIZATION_LABELS.md). Человеческая проверка исходных меток отсутствует. Второй AI-проход не превращает их в экспертный gold. Набор использован для поиска ошибок и разработки; улучшение на нём не измеряет перенос на новые компании/события. Некоторые нормы и компании зависимы; адресные события о членах обезличенной группы не покрыты.

Графы для raw-входа и v2 пересчитаны по соответствующим полям событий. Raw other не наследует отраслевые совпадения курированного входа. Снимки графа привязаны хешами к профилям, извлечению и реализации графа; повторный прогон возможен без исходной SQLite.

```bash
node --import tsx scripts/extract_personalization_events.ts --mode curated --input data/personalization/events.json --out data/personalization/evaluation/curated_extracted.json
node --import tsx scripts/extract_personalization_events.ts --mode articles --input data/personalization/articles.json --out data/personalization/evaluation/articles_extracted.json
python scripts/evaluate_personalization.py --input data/personalization --out data/personalization/evaluation --graph-snapshots data/personalization/evaluation/graph_snapshots.json --report docs/reports/PERSONALIZATION_COMPARISON.md
```

При изменении извлечения/правил графа пересоберите снимки: вместо `--graph-snapshots` укажите `--database data/processed/company_context.sqlite` с полной исходной базой, соответствующей сохранённым хешам. Маленькая база синтетических компаний для CI будет отклонена.

Машиночитаемые результаты: `data/personalization/evaluation/metrics.json`, `scores.json`, `predictions.json`, `comparison.json`, `graph_snapshots.json`. В метриках записаны хеши исходных меток и кода; несовпадающий или неполный набор отклоняется.
