## Изменения

1. Промпт v5 согласует генерацию с действующими правилами чисел. Summary рекомендуется копировать из полных fact.quote / bank.quote, связывать их индексами и отделять качественное AI-пояснение. Даты, годы, ОКВЭД, номера стандартов и знак/формат ставки сохраняются дословно. Дата из metadata не становится цитатой заголовка.
2. `response_guidance` формирует ограниченные примеры только из разрешённых источников текущего prepared-контекста: text=quote, source_id, форма summary/grounding либо answer/claim_indexes. Нет исправления ответа за модель, подмены цитаты или автоматического удаления чисел ради принятия.
3. Repair получает проверенные ошибки, конкретное правило для их исправления, те же допустимые примеры и итоговый список проверок. Валидатор prepared-ответа собирает независимые нарушения разных полей; после изменения claims перепроверяются все привязки, conditions и missing_data.
4. `diagnostics.issues` по-прежнему означает текущий отказ; необязательная `history` сохраняет до двух попыток по десять ошибок, в том числе смену нарушения при неудачном repair. История фильтруется allowlist, хранится в прежней таблице безопасных снимков и проходит существующий HTTP/UI-контур. Исходные строки модели и секреты не добавляются.
5. Число вызовов не увеличено: исходная генерация + одно исправление. HTTP/auth/quota/timeout/refusal/truncation не вызывают слепой повтор. Настройки none/6000 и обе формы JSON остаются поддержаны.

## Что этим не измерено

Внешняя модель не вызывалась, поэтому после исправления не заявляется новый live acceptance rate и не заявляется, что реальные 1/4 превратились в 4/4. Для подтверждения требуется повторить тот же сохранённый live-набор с исходными input и ответами. Docker отсутствует локально; compose-smoke выполняет существующий CI.

Безопасный ручной контроль: сохранить в личном .env прежние model/none/6000/json_object, выполнить разрешённый live-прогон, сопоставить failures по generation_id и diagnostics.history; не увеличивать число попыток и не обходить отказ валидатора. Наличие дословной цитаты подтверждает соответствие тексту, а не истинность первоисточника или качество причинного анализа.
