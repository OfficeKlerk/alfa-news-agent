Основа — присланное распределение команды. Матвей: **роль 3 Backend/RAG**. Конкретные исполнители остальных ролей пока не указаны. Это локальный план, GitHub Issues ещё не созданы. «Есть» означает текущую реализацию, а не соответствие всем требованиям роли.

Есть: профиль из CSV, агрегаты платежей, эвристическое ранжирование и текстовые причины. Нет: ML/LLM reranking, обучающий датасет и автоматическая оценка персонализации.

| ID | Работа | Критерий готовности | Зависимости |

FastAPI из распределения заменяется предложением Node.js/Express; решение ещё согласовать.

## Общее правило сдачи

Для кода: typecheck + test + build, целевые проверки изменённого поведения; для UI — ручной сценарий. В PR: что изменилось, проверка, риски, миграция данных/контракта при необходимости. Задача считается выполненной по критерию, а не по наличию документа или названию функции. Платные массовые прогоны требуют согласованного командного бюджета.
