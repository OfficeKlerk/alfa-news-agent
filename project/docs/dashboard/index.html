Обоснованность выводов LLM (grounding)

Каждый вывод привязан к источнику механизм активен

Жёсткая проверка генерации (PR #8, server/integration/grounding.js) — не доверяем модели на слово.

  • Факт — дословная цитата (≥8 символов) из выбранного источника новости.
  • Позиция банка — дословная цитата из датированного фрагмента аналитики; нет материала → не выдумывается.
  • Вывод AI — только с условиями и ссылкой на конкретный признак профиля (не «весь профиль»).
  • Числа в выводах должны присутствовать в источниках; при нарушении — 1 повтор, затем ошибка.
Метрика на поток: доля анализов, прошедших валидацию grounding, и доля ответов ревью со `score=2`. Абсолютный % считается при live-прогонах (расходует бюджет) — сейчас отслеживается событийно в логах.
